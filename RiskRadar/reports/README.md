# Final project report

`Final_Rainfall_and_Flood_Risk_Analysis_Report.docx` describes the current two-page Rainfall and Flood application, historical ERA5 analysis and the restored RiskRadar XGBoost assessment. It follows the retained Applied Data Science checklist template, includes six measured charts and two current interface screenshots, and reports the active model's reconstructed evaluation separately from application examples. Team identity, contribution and signature fields remain blank for completion by the team.

The previous report is preserved at `history/Previous_Rainfall_Severity_Report_before_RiskRadar_Final.docx`. Its retired model results are not the active predictor's metrics.

`riskradar_final_work/` holds the unchanged reference template, template contract, report builder, calculated statistics, figure sources, fidelity/accessibility audits and internal page-render evidence. These working files are not additional submission deliverables. No software/data/API check totals or separate limitations section are included in the final academic report.

The inference-only verification of the exact deployed model is documented in `../evaluation/existing_model/EVALUATION.md`. Its reproduced results agree with the Word report: 96.89% accuracy, 65.64% positive precision, 79.08% positive recall and 71.74% positive F1. The report labels these as reconstructed evaluation results. Separate retraining experiments do not evaluate the deployed model and are not substituted into the report.
